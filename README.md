# RabTech-Task-05
## Query Index Tuning, Execution Plans & ACID Transactions

### Project Overview
This project demonstrates database query optimization and transaction management using PostgreSQL.

### Technologies Used
- PostgreSQL
- pgAdmin 4
- SQL

### Tasks Completed
- Created B-tree indexes.
- Implemented composite indexes.
- Implemented partial indexes.
- Analyzed query execution plans using EXPLAIN ANALYZE.
- Updated database statistics using ANALYZE.
- Demonstrated COMMIT and ROLLBACK.
- Implemented SAVEPOINT.
- Demonstrated SERIALIZABLE transaction isolation.

### Project Files
1. `optimization_report.md` – Optimization report and execution-plan observations.
2. `transaction_scripts.sql` – SQL scripts for indexing and ACID transactions.
